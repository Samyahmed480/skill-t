# 🚀 Antigravity ✕ Telegram Bridge & Remote Control

حزمة متكاملة وسكيل ذكي لنظام **Google Antigravity** يتيح لك التحكم في بيئة عملك، تنفيذ الأوامر، وتلقي الإشعارات الفورية وتقارير الإنجاز وطلبات الموافقة مباشرة عبر تطبيق **تيليجرام** على هاتفك المحمول، مع لوحة تحكم ويب عصرية وسهلة للربط والإدارة.

📖 **[اضغط هنا لفتح الدليل الشامل والمفصل (TELEGRAM_CONTROL.md)](./TELEGRAM_CONTROL.md)**

---

## 🌟 الميزات الرئيسية (Key Features)

1. **تحكم كامل عن بُعد عبر Telegram**:
   - `/status` : عرض حالة النظام، استهلاك المعالج، والذاكرة والمساحة المتبقية.
   - `/exec <أمر>` : تنفيذ أي أمر PowerShell على جهازك وتلقي الناتج لحظياً في الدردشة.
   - `/dir [مسار]` : استعراض الملفات والمجلدات داخل المشروع.
   - `/read <ملف>` : قراءة محتوى أي ملف نصي أو إرساله تلقائياً.
   - `/sendfile <ملف>` : رفع وإرسال ملف من جهازك إلى التيليجرام مباشرة.
   - `/logs` : قراءة آخر سجلات نشاط النظام والبوت.
   - `/ping` : فحص سرعة الاتصال.

2. **لوحة تحكم وإدارة ويب عصرية (Web Dashboard)**:
   - تصميم زجاجي داكن (Dark Glassmorphism) سريع وخفيف ويعمل بدون الحاجة لأي مكتبات إضافية.
   - فحص وتأكيد التوكن لحظياً مع خوادم تليجرام.
   - زر **الاكتشاف التلقائي للآيدي (Auto-Detect Chat ID)** بنقرة واحدة لربط حسابك كمدير.
   - أزرار تشغيل وإيقاف البوت في الخلفية (Daemon Process Controller).
   - مرسل إشعارات وتنبيهات تجريبية مباشرة من المتصفح إلى هاتفك.
   - شاشة طرفية حية (Live Console) لمتابعة كل الرسائل والأوامر المنفذة.

3. **سكيل مزدوج (Dual Antigravity Skill)**:
   - **السكيل العام (Global)**: تم تثبيته في `~/.gemini/config/skills/telegram-control/` ليكون متاحاً في كل مشاريعك مع Antigravity.
   - **سكيل المشروع (Workspace)**: موجود في `.agents/skills/telegram-control/`.

4. **أدوات سطر أوامر مخصصة للوكيل (Agent Tools)**:
   - `python scripts/send_notification.py` : إرسال إشعارات وتقارير وملفات للمستخدم.
   - `python scripts/wait_for_approval.py` : إرسال أزرار موافقة/رفض (`[Approve] / [Reject]`) وانتظار رد المستخدم من تليجرام قبل تنفيذ العمليات الحساسة.
   - `python scripts/bot_daemon.py` : خادم الاستماع المستمر في الخلفية.

## 🚀 طريقة البدء والتشغيل (Quick Start)

### 1. تشغيل لوحة التحكم (Web Dashboard)
انقر مرتين على الملف:
```cmd
start_dashboard.bat
```
أو عبر سطر الأوامر:
```bash
python server.py
```
ثم افتح الرابط في المتصفح:
👉 **[http://localhost:8765](http://localhost:8765)**

---

### 2. خطوات ربط البوت بحسابك:
1. افتح تطبيق تيليجرام وابحث عن `@BotFather`.
2. أرسل الأمر `/newbot` واتبع التعليمات لإنشاء بوتك الخاص والحصول على الـ **Token**.
3. افتح لوحة التحكم `http://localhost:8765`، الصق التوكن واضغط **🔍 فحص**.
4. افتح البوت الجديد في تليجرام وأرسل له أي رسالة (مثلاً `/start` أو `مرحبا`).
5. في لوحة التحكم اضغط **⚡ اكتشاف تلقائي**، ثم اضغط **+ تعيين كمدير** بجانب اسمك.
6. اضغط **💾 حفظ الإعدادات**.
7. اضغط **▶️ تشغيل البوت** في أعلى لوحة التحكم!

مبروك! الآن يمكنك التحكم بجهازك ومتابعة Antigravity من هاتفك في أي وقت ومن أي مكان.
